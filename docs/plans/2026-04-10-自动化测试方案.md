## 当前可用 API

### HTTP API（已实现）

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/debug/status` | GET | 获取当前播放状态（drift、position等） |
| `/api/debug/log` | GET | 获取最近 100 行日志 |
| `/api/library/upload` | POST | 上传音乐文件 |
| `/api/library/list` | GET | 获取音乐库列表 |

### WebSocket API（需模拟）

| 消息类型 | 功能 |
|---------|------|
| `createRoom` | 创建房间 |
| `joinRoom` | 加入房间 |
| `play` | 开始播放 |
| `pause` | 暂停 |
| `seek` | 跳转 |

## 自动化测试方案

### 方案 A：服务端模拟播放（推荐）

**原理**：在服务器端创建一个模拟房间，直接触发播放逻辑，无需浏览器

**步骤**：
1. 通过 HTTP API 上传测试音乐（或使用已有音乐）
2. 在 Go 代码中添加 `/api/debug/play-test` 端点
3. 调用该端点触发服务端播放状态
4. 通过 `/api/debug/status` 监控 drift

**优点**：
- 无需浏览器交互
- 完全自动化
- 可快速迭代

**缺点**：
- 只测试服务端逻辑
- 不涉及 Web Audio API（客户端播放）

---

### 方案 B：Node.js 模拟客户端

**原理**：用 Node.js + ws 库模拟 WebSocket 客户端

**步骤**：
1. 在服务器上创建 Node.js 脚本
2. 脚本连接 WebSocket，发送 joinRoom + play 命令
3. 脚本持续发送 sync 数据，监控 drift
4. 通过 SSH 执行脚本

**优点**：
- 测试完整的 WebSocket 流程
- 可模拟多客户端同步

**缺点**：
- 需要 Node.js 环境
- 不涉及 Web Audio API

---

### 方案 C：Python 自动化浏览器

**原理**：用 Selenium/Playwright 自动操作浏览器

**步骤**：
1. 本地运行 Python 脚本
2. 脚本打开浏览器，访问网站
3. 自动点击创建房间、播放按钮
4. 脚本监控 Console 输出

**优点**：
- 测试完整的客户端流程
- 可获取 Console 日志

**缺点**：
- 需要本地浏览器
- 用户仍能看到播放（但可静音）

---

## 推荐方案：A + B 组合

### Phase 1：服务端模拟播放

添加 `/api/debug/play-test` 端点：

```go
// 在 main.go 中添加
mux.HandleFunc("/api/debug/play-test", func(w http.ResponseWriter, r *http.Request) {
    // 创建测试房间
    roomCode := "TEST" + randomSuffix()
    rm := manager.CreateRoom(roomCode, "test-client", "Test Host")
    
    // 设置测试音频（使用已有音频）
    audioInfo := &room.AudioInfo{
        ID: "test-audio",
        Title: "Test Track",
        Duration: 30.0,
        Qualities: map[string]string{
            "medium": "/data/rooms/test/test-audio-medium.flac",
        },
    }
    rm.Audio = audioInfo
    
    // 触发播放状态
    rm.State = "playing"
    rm.Position = 0.0
    rm.StartTime = time.Now().UnixMilli()
    
    // 返回房间码
    json.NewEncoder(w).Encode(map[string]string{
        "roomCode": roomCode,
        "status": "playing",
    })
})
```

### Phase 2：Python WebSocket 客户端

```python
# ssh_helper.py 中添加
import websocket
import json
import time

def test_sync():
    ws = websocket.create_connection("wss://107.172.234.183:8443/ws")
    
    # 加入测试房间
    ws.send(json.dumps({
        "type": "joinRoom",
        "roomCode": "TEST1234",
        "clientTime": time.time() * 1000
    }))
    
    # 模拟播放
    ws.send(json.dumps({
        "type": "play",
        "position": 0.0,
        "clientTime": time.time() * 1000
    }))
    
    # 监控 drift
    for i in range(30):
        time.sleep(1)
        # 发送 sync 数据
        ws.send(json.dumps({
            "type": "sync",
            "clientTime": time.time() * 1000,
            "position": i  # 模拟客户端位置
        }))
        # 获取状态
        resp = requests.get("https://107.172.234.183:8443/api/debug/status")
        print(resp.json())
    
    ws.close()
```
